# 분할 리뷰 결과 취합 보존

분할 리뷰와 전역 리뷰가 완료된 뒤 같은 finding을 LLM에 재작성시키면 출력 길이 제한 또는 필드 변경으로 최종 정합성 검사가 실패한다. 입력 리뷰 내용 자체는 이미 검증됐으며 최종 변환에서 새 판단을 할 필요가 없다.

- 모든 내부 리뷰가 완료되면 시스템은 검증·중복 제거된 finding을 최종 게시 모델로 결정적으로 변환해야 한다.
- 변환 시 시스템은 category, file, line, description, suggestion, confidence, spec_status, aligned, prior_resolved를 기존 계약대로 보존해야 한다.
- 변환이 끝나면 시스템은 기존 finding 집합 정합성 검사를 수행해야 한다.
- 내부 리뷰 응답이 불완전하거나 범위를 벗어나면 시스템은 실패를 유지해야 한다.
- 시스템은 단일 리뷰 경로, 파일 범위 검사, 판정 기준과 비용 상한을 유지해야 한다.
